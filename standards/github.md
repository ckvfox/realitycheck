# GitHub Standard

Version: 2.0.0

## Minimum requirements

- at least one workflow exists in .github/workflows/

## Workflow security

- only secrets context for credentials
- no hardcoded tokens

## Recommended templates

- .github/pull_request_template.md
- .github/ISSUE_TEMPLATE/bug_report.md
- .github/ISSUE_TEMPLATE/feature_request.md

## Governance

- pull requests should include scope, risk and test notes
- security and deployment changes require elevated review attention
