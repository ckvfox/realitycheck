# AGENTS Standard

Version: 2.0.0

## Required sections in AGENTS.md

- Projekt
- Lokale Entwicklung
- Build
- Deployment
- Bekannte Probleme
- Framework Candidates
- Lessons Learned
- Restricted Files
- Allowed Work
- Deployment Packaging Rules

## Recommended section

- Known Constraints

## Security boundaries

AGENTS.md must never contain:

- passwords
- API keys
- credentials
- secrets

## Deployment reference

AGENTS.md should reference standards/deployment.md and not define conflicting packaging rules.
